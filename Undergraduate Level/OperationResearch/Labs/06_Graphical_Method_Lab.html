Graphical Method Lab

Linear programs with two variables, drawn and solved in GeoGebra · runs in the browser, nothing to install (needs internet: GeoGebra loads from geogebra.org). In every applet, x is the first variable and y the second.

Sandbox · write and plot your own model

Plot it yourself: lines, feasible region, objective line, corners

A full GeoGebra window: type in the Input bar (left), press Enter, the object appears in the graph. Pick a problem to see its statement; changing the problem only moves the view, your drawing stays (use Clear to start again). Take a screenshot when you are done.

What to type (shown on the carpenter: x is t, y is c)
2x + y = 40a line: the boundary of a constraint
2x + y <= 40 && x + 2y <= 50 && x >= 0 && y >= 0the feasible region (all constraints at once); a ≥ constraint is typed >=
z = Slider(0, 15000, 100) then 500x + 300y = zan objective line you can move with the slider
A = Intersect(2x + y = 40, x + 2y = 50)a corner: the intersection of two lines
500 x(A) + 300 y(A)the value of z at the corner A
B = (20, 0)a point typed directly

Maximize: push the objective line as far as it still touches the region. Minimize: pull it back as far as it still touches the region. The last point touched is the optimum.

Lab 1 · The graphical method, step by step

Feasible region → objective line → the last corner it touches
  1. Which side of each line is feasible? Check that the blue region satisfies every constraint.
  2. Move the slider z. Maximize: what is the largest z for which the orange line still touches the region? Minimize: the smallest?
  3. Tick Show the corners: is the optimum one of them? Then tick Show the optimum to check.
Answers

Carpenter: corners (0, 0) z = 0, (20, 0) z = 10,000, (10, 20) z = 11,000, (0, 25) z = 7,500. Optimum t = 10, c = 20, z = $11,000: both constraints are tight.

Dorian: the region is unbounded upwards, but we minimize. Corners (0, 14) z = 1,400, (3.6, 1.4) z = 320, (12, 0) z = 600. Optimum x₁ = 3.6, x₂ = 1.4, z = 320.

E: x₁ ≤ 2 → (2, 3.89), z = 41.11; x₁ ≥ 3 → (3, 3), z = 39 (pruned by bound once 40 is found).
